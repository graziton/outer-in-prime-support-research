# OEIS Materials

The `release/oeis/` directory contains the frozen OEIS material included in the 2026-09-22 final research package.

Those files are intentionally preserved unchanged.

The current submission status is documented separately in:

`SUBMISSION_STATUS_2026-09-23.md`

The frozen draft files should not be assumed to exactly match the latest submitted OEIS text because editor-requested changes were made after the release was frozen.
