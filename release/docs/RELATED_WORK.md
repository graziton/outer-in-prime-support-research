# Related work and novelty position

The closest located OEIS entries are:

- A110751 — numbers n such that n and its digital reversal have the same prime divisors.
- A110819 — non-palindromic numbers in A110751.
- A244514 — numbers for which all cyclic permutations of the decimal digits have the same prime divisors.
- A371307 — the smallest nonpalindromic number in each base having the same prime divisors as its digit reversal.

The present transformation is different from reversal and from a cyclic orbit: it
uses the fixed outer-in order first-left, first-right, second-left, second-right,
and so on.

The broader literature on digit permutations includes permutiples, in which an
integer is an integer multiple of a permutation of its digits. Relevant references
include Benjamin V. Holt, *On Permutiples Having a Fixed Set of Digits* (INTEGERS
17, 2017, A20), and Holt, *A Method for Finding All Permutiples with a Fixed Set
of Digits from a Single Known Example* (INTEGERS 24, 2024, A88). Those works
study multiplicative digit-permutation relations, not the equal-prime-support
condition used here.
